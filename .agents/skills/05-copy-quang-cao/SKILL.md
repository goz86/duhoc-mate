# Copy Quảng Cáo

## Thu thập thông tin
1. Sản phẩm & USP
2. Audience (từ product-marketing-context)
3. Kênh ads (Facebook/TikTok/Google)
4. Mục tiêu (traffic/conversion/retarget)

## Cấu trúc output: 6 biến thể

### TOFU (2 biến thể) — Thu hút
- Biến thể 1: Hook awareness + giá trị + CTA mềm
- Biến thể 2: Hook tò mò + nỗi đau + giải pháp

### MOFU (2 biến thể) — Nuôi dưỡng
- Biến thể 3: Bằng chứng + case study + CTA
- Biến thể 4: So sánh + khác biệt hóa + CTA

### BOFU (2 biến thể) — Chốt đơn
- Biến thể 5: Khẩn cấp + offer + CTA mạnh
- Biến thể 6: Retarget + social proof + CTA

## Mỗi biến thể gồm
- **Headline:** Gây chú ý
- **Primary text:** Thân bài
- **CTA:** Kêu gọi hành động
- **Ghi chú:** Khi nào nên dùng biến thể này
